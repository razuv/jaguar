# Лиза Егорушкина — портфолио

Статический сайт без сборки. Файлы сайта находятся в `dist/`.

Для просмотра: `python3 -m http.server 4173 --directory dist`, затем открыть http://localhost:4173.

Материалы: резюме .doc, пользовательский скрин аналитики, предоставленная презентация (скачана через Google Drive). Вакансия Burger King: https://hh.ru/vacancy/137581946.

Кейсы различают личный вклад и результат команды. Цифры личного аккаунта не суммируются с результатами клиентов. Два видео имеют округлённые площадкой отметки «1 млн». Период аналитики не установлен. 1000+ комментариев X5 — из стороннего упоминания в презентации.

Неподтверждённые компетенции (ежедневное применение ИИ, ТВ/POSM, франчайзинговое управление) не заявлены. Даты опыта взяты из резюме: в презентации работа в «виноу» описана как текущая, но в резюме окончание — сентябрь 2026.

Визуальная проверка оставлена пользователю по его просьбе. Шрифты загружаются из Google Fonts; при недоступности работают запасные шрифты.
