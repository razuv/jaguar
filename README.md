# Лиза Ягуарушкина — портфолио

Статический сайт без сборки. Основные файлы находятся в корне проекта:

- `index.html` — страница и контент;
- `style.css` — оформление;
- `app.js` — оставлен как не подключённый файл; страница работает без JavaScript;
- `assets/` — изображения, логотипы, шрифты и резюме.

## Локальный просмотр

В папке проекта запустить:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173/. После правок обновить страницу.

Все последующие изменения показываем только локально. Sites больше не используется. Коммиты, push и публикация — только после отдельного одобрения пользователя.

## GitHub Pages

Проект готов к размещению из корня ветки `main`; файл `.nojekyll` отключает обработку Jekyll. Пути к ресурсам относительные и подходят для адреса вида `https://razuv.github.io/jaguar/`.

GitHub-репозиторий: https://github.com/razuv/jaguar. Он подключён как `origin`. Источник GitHub Pages: **Deploy from a branch → main → /(root)**. Адрес сайта: https://razuv.github.io/jaguar/. Последующие коммиты, push и публикации требуют отдельного одобрения пользователя.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Материалы

Контент взят из предоставленного резюме и портфолио Лизы. Источники логотипов находятся в `assets/logos/SOURCES.md`; лицензия Bounded — в `assets/fonts/OFL.txt`. Подтверждения результатов в `assets/proofs/` сохранены без изменения исходных файлов.

Визуальную проверку выполняет пользователь. Предыдущие заметки проекта сохранены локально в `.local/migration/` и не входят в Git.
