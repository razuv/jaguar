# Лиза Егорушкина — портфолио

Статический сайт без сборки. Файлы сайта находятся в `dist/`.

Для просмотра: `python3 -m http.server 4173 --directory dist`, затем открыть http://localhost:4173.

Материалы: резюме .doc, пользовательский скрин аналитики, предоставленная презентация (скачана через Google Drive). Вакансия Burger King: https://hh.ru/vacancy/137581946.

Кейсы различают личный вклад и результат команды. Цифры личного аккаунта не суммируются с результатами клиентов. Два видео имеют округлённые площадкой отметки «1 млн». Период аналитики не установлен. 1000+ комментариев X5 — из стороннего упоминания в презентации.

Неподтверждённые компетенции (ежедневное применение ИИ, ТВ/POSM, франчайзинговое управление) не заявлены. Даты опыта взяты из резюме: в презентации работа в «виноу» описана как текущая, но в резюме окончание — сентябрь 2026.

Визуальная проверка оставлена пользователю по его просьбе. Шрифты загружаются из Google Fonts; при недоступности работают запасные шрифты.

Обновление: название «Лиза Ягуарушкина», шрифт Bounded локально (SIL OFL, автор Vlad Churkin), Hugeicons из официального static-репозитория. Скриншоты заменены текстовыми результатами и цитатами. Портрет с прозрачным фоном подготовлен встроенным imagegen: «Remove only the background; preserve the woman, cat, identity, pose, hair and fur; output transparent alpha». Актив: `dist/assets/liza-cutout.png`.

Первый блок центрирован: новый портрет без фона, симметричные показатели и подпись про волосы и Бургер Кинг. Актив: `dist/assets/liza-hair-cutout.png`. Встроенный imagegen использован для удаления фона с сохранением лица, волос, одежды и позы; проверен альфа-канал. Композиционные референсы изучены в галерее портфолио Awwwards и сохранённой странице Martin Briceno — Portfolio. Визуальные тесты сайта не запускались по просьбе пользователя.

Обновление большого экрана: сгенерирован шуточный редакционный образ Лизы в бумажной короне с бургером и картошкой, прозрачный фон. Актив `dist/assets/liza-burger-hero.png`; встроенный imagegen, референс — пользовательский портрет, лицо/волосы/костюм сохранены как ориентир. Цифры в HTML, не в картинке. Мем с шариками — оригинал из портфолио. Публичные технические оговорки удалены по прямому запросу пользователя; происхождение цифр сохраняется выше в этом файле.

Последняя структура: фотография на весь viewport, точная подпись «Готова стать вашей бургер-квин», показатели вертикальным списком внизу. Хедер, футер, мемный коллаж, общий блок соответствия вакансии и длинная биография удалены. Далее — клиентские проекты и компактный опыт/контакт.

Логотипы получены из подлинных файлов (источники в dist/assets/logos/SOURCES.md). Engagement rate удалён из интерфейса. Пруфы открываются по отдельным кнопкам: 1000+ комментариев X5, показы/взаимодействия X и два ролика по миллиону. Все доказательства — точные копии предоставленных исходников; SVG viewport показывает нужные участки без изменения изображения. В аналитике видны только карточки показов и взаимодействий. Исходники не перерисовывались.

Отзывы переписаны из изображений 14, 8 и 23 исходного портфолио. Первый отзыв полный; второй представлен двумя точными фрагментами с многоточием; третий — цитата о проекте с 11 университетами без завершающих эмодзи. Имена, должности и компании авторов не приписываются. Подтверждения X5 и двух видео отображаются в блоках целиком, без обрезки. Составной скрин аналитики с ER не показывается. Финальный блок использует исходный пользовательский images-11.jpeg.
